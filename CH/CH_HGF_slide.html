条件づけ幻覚タスク（CH Task）の仕組み

1. 刺激提示フェーズ

  • 視覚刺激（チェッカーボード）を1秒間提示[cite: 1]
  • 同時に微弱な純音（1kHz）を提示/不提示[cite: 1]
  • 「音が聞こえたか（Yes/No）」を回答[cite: 1]

2. 条件づけ操作

  • タスク前半は画像と75%閾値の音を高頻度で対提示[cite: 1, 2]
  • 「画像が出たら音が鳴る」という関連性（Prior）を無意識に学習させる[cite: 1, 2]

3. 条件づけ幻覚

  • タスク後半に向けて音なし（No-Tone）試行を増加[cite: 1, 2]
  • 音がないのに「聞こえた」と回答した現象を【条件づけ幻覚】と定義[cite: 1, 2]

脳の意思決定ルール：「ベイズ推論」

事前信念（Prior: 予測・期待）＋ 感覚入力（Sensory Input: 実際の音）＝ 最終的な知覚（Perception）[cite: 1, 2]
※ 脳は外の世界の情報をそのまま受容するのではなく、過去の経験に基づく「予測」と合体させて世界を解釈している。

日常の例え：暗い部屋の服

  • 「泥棒がいるかも」という強い予測（Prior）
  • 目から入る「ハンガーにかかった服」の曖昧な感覚入力
  • 両者が合体し、「人が立っている！」と誤認する。

条件づけ幻覚への応用

  • 「画像が出たから音が鳴る」という強固な予測[cite: 1, 2]
  • 「無音」というあやふやな音覚入力[cite: 1, 2]
  • 予測が勝り、「音が存在する」と誤った知覚が成立。[cite: 1, 2]

HGF（階層ガウスフィルタ）の3階層構造

第3層 (X₃): 環境の変動性 (Volatility)[cite: 1]

意味: 「この実験のルールはどれくらい変わりやすいか？」[cite: 1] | 関連脳部位: 小脳虫部[cite: 1]

第2層 (X₂): 連合強度・ルール (Contingency)[cite: 1]

意味: 「画像が出たら音が出る確率は何％くらいか？」[cite: 1] | 関連脳部位: 海馬 / 海馬傍回・小脳[cite: 1]

第1層 (X₁): 知覚的信念 (Perceptual Belief)[cite: 1]

意味: 「今、まさに音が聞こえたか？ (1 or 0)」[cite: 1] | 関連脳部位: 上側頭溝 (STS) / 前部インスラ (AIC)[cite: 1]

幻覚を引き起こすカギ：事前信念への過度な重み付け (ν)

健常な脳のバランス (ν が標準)[cite: 1]

  • 事前予測と現実の音入力を対等に比較[cite: 1]
  • 音が存在しない試行では「無音」の感覚信号を正しく採用[cite: 1]
  • 「聞こえなかった（正棄却）」と正解を導く[cite: 1]

幻覚が生じる脳 (ν > 1 : Strong Prior)[cite: 1, 2]

  • 事前予測への信頼度パラメータ ν (Nu) が過剰に高値[cite: 1]
  • 「音が出るはず」という予測が実際の「無音」信号を圧倒[cite: 1, 2]
  • 外界信号がないにもかかわらず「聞こえた」と誤認[cite: 1, 2]

研究結果：Powers et al. (2017) の主要発見

発見1: 幻覚体験者に共通する計算傾向[cite: 2]

  • 精神病の有無に関わらず、日常的に幻聴を体験するグループ（P+H+, P-H+）はパラメータ ν が有意に高値[cite: 1, 2]
  • 「診断名」ではなく「幻聴体験の有無」が Prior への過度な重み付けと直接連動[cite: 2]

発見2: 階層的信念更新の脳内マッピング[cite: 1]

  • HGFモデルの信念軌跡がfMRIの脳活動と連動[cite: 1]
  • X₁: 上側頭溝 (STS), 前部インスラ (AIC)[cite: 1]
  • X₂: 海馬 / 海馬傍回、小脳[cite: 1]
  • X₃: 小脳虫部[cite: 1]

まとめ：計算論的精神医学がもたらす革新

  • 1. 幻覚の再定義: 幻覚は脳の機能低下ではなく、事前予測（Prior）と感覚入力の統合における重み付け（ν）の偏りによって生じる計算エラー[cite: 2]。
  • 2. 共通モデルの確立: HGF（階層ガウスフィルタ）を用いることで、精神病患者と健常幻覚者に共通する『Strong Prior』の病態メカニズムを定量的・数学的に証明[cite: 1, 2]。
  • 3. 臨床への応用可能性: 患者の主観的な「幻覚体験」を客観的な数値パラメータ（ν）および脳画像バイオマーカーに還元できる可能性を示した[cite: 1, 2]。
